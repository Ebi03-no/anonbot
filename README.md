🎭 لیست کامل قابلیت‌های ربات Hidden Chat
| قابلیت | توضیح |
|---|---|
| 🔗 لینک اختصاصی (Deep Link) | هر کاربر لینک یکتا با کد ۸ رقمی می‌گیرد؛ هر کس لینک را باز کند ناشناس پیام می‌دهد |
| 🎭 حالت گفتگوی مداوم | بعد از باز کردن لینک، پیام‌ها بدون تایپ دوباره ادامه می‌یابند تا `/stop` |
| ↩️ پاسخ به پیام خاص (Reply) | با دکمه «پاسخ» زیر هر پیام + نقل‌قول خودکار متن اصلی |
| 📸 پشتیبانی از رسانه | عکس، ویس، ویدیو، موسیقی، ویدیو دایره‌ای، فایل، استیکر — همه با کپشن ناشناس رله می‌شوند |
| 📥 مینی‌اپ تلگرام (صندوق ورودی) | رابط وب داخل تلگرام: دیدن ۵۰ پیام آخر، کپی و اشتراک‌گذاری لینک، طراحی شیشه‌ای تیره |

🛡 امنیت و محافظت
| قابلیت | توضیح |
|---|---|
| 🤖 نگهبان هوشمند (AI) | تحلیل هر پیام با Workers AI (Llama 3.2)؛ توهین و تهدید قبل از رسیدن رد می‌شود |
| 🔤 فیلتر کلمات (لایه ۱) | فهرست کلمات ممنوعه برای پاسخ فوری بدون صرف سهمیه AI |
| 🚫 بلاک کاربر مزاحم | با تأیید دومرحله‌ای؛ فرستنده بلاک‌شده دیگر پیامش نمی‌رسد |
| 🔄 بلاک دوطرفه | بررسی بلاک در هر دو جهت قبل از هر ارسال |
| ⏳ محدودیت ضداسپم | حداکثر ۱۰ پیام در دقیقه برای هر کاربر (با KV و TTL) |
| 📏 محدودیت طول | حداکثر ۱۰۰۰ کاراکتر متن یا کپشن |
| 🔐 احراز هویت مینی‌اپ | اعتبارسنجی امضای HMAC مطابق استاندارد رسمی تلگرام + سقف زمانی ۲۴ ساعت |
| 🧼 ضد XSS | escape کردن HTML همه متن‌های کاربران |

🎛 رابط کاربری
| قابلیت | توضیح |
|---|---|
| 🔘 دکمه‌های شیشه‌ای | منوی اصلی: لینک من، راهنما، بلاک‌شده‌ها، پایان گفتگو |
| 📱 دکمه وب‌اپ | ورود مستقیم به صندوق ورودی از داخل چت |
| ✅ بازخورد فوری | پاسخ لحظه‌ای دکمه‌ها با Toast + پیام‌های وضعیت (ارسال شد / رد شد) |
| 🆔 نمایش نوع پیام | در صندوق ورودی: آیکون و برچسب هر نوع (📷 عکس، 🎙 ویس...) |
| 👋 خوش‌آمدگویی کامل | لینک اختصاصی + راهنما در `/start` |

⚙️ فنی و زیرساختی
| قابلیت | توضیح |
|---|---|
| ☁️ بدون سرور | Cloudflare Workers — بدون هزینه سرور، مقیاس‌پذیر خودکار |
| 🗄 دیتابیس D1 | ذخیره کاربران، کدها، پیام‌ها و بلاک‌ها با SQLite |
| ⚡ کش KV | سشن‌ها، نرخ ارسال، نقل‌قول‌ها و نام ربات |
| 🕸 مسیر Webhook مخفی | `webhook/<SECRET>` — جلوی ارسال جعلی آپدیت‌ها |
| 🛡 مدیریت خطا | بستن خودکار سشن وقتی گیرنده ربات را بلاک کرده |
| 🎲 کدهای تصادفی امن | تولید با `crypto.getRandomValues` + تلاش مجدد در برابر تکراری بودن |
